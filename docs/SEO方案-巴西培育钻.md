## 0. 现状诊断（你 vs 市场）

**你的店铺(基准):**
- 域名 `1999diamonds.myshopify.com`——**还没绑自定义域名**,商品是 **INATIVO(草稿)**,**店没上线、没被谷歌收录**。

**市场(机会):**

## 1. 战略原则（怎么打）

1. **吃长尾,不碰大词**:主攻带 `cultivado / de laboratório / lab grown` 修饰的词;大词(ouro 18k 裸词)后期用内链带。
2. **占住信任/辟谣词**:`é falso? / vale a pena? / perde valor?` ——这是巴西特有的转化金矿。
3. **从第一天就"结构碾压"**:关键词化标题 + 可收录的筛选页 + 科普中心 + schema,四件一起上(没人全做到)。
4. **术语纪律**:全站统一 **「diamante cultivado em laboratório」/「lab grown」**,**绝不用「sintético」**(巴西人听成"假货",Aurora 就踩了这个雷)。
5. **把 Pix/parcelado/laudo IGI 当关键词**:写进标题和 meta,不只当功能点。

## 3. 站点结构（Shopify 架构）

**目标:造出尽量多"可被收录的长尾落地页"**(竞品几乎都只有粗集合页)。

```
/ (首页)
├── /collections/aneis-de-noivado           ← 招牌集合
│   ├── 按形状: oval / redondo / almofada / esmeralda / princesa / gota ...
│   ├── 按金属: ouro-branco-18k / ouro-amarelo-18k / ouro-rose-18k / platina
│   └── 按克拉: 1ct / 1-5ct / 2ct
├── /collections/aliancas                    ← 对戒
├── /collections/brincos (ponto de luz)      ← 耳钉(走量引流)
├── /collections/colares-pingentes
├── /collections/pulseiras (riviera)
├── /diamante-cultivado                      ← 科普中心(pillar page)
│   └── /blog/... (各科普/异议文章)
└── /sobre / /garantia-e-cuidados / /certificado-laudo
```

**要点:**
- **按形状/金属/克拉建"独立集合页"**(不是只靠筛选参数)——每个都是一个可排名的长尾落地页。竞品里只有 Poésie 做了,Shopify 对手(Gaem/Niliz)只有粗集合。
- **科普中心 `/diamante-cultivado`** 作 pillar page,博客文章内链回它 → 积累话题权威。
- URL 用葡语短词:`/collections/aneis-de-noivado-ouro-branco-18k`。
- **内链**:博客(认知) → 集合页(购买);形状文章 → 对应形状集合页。

## 4. On-page 模板（pt-BR,Shopify 直接套）

## 5. 结构化数据（Schema / 富媒体摘要)

竞品几乎没做全——**全做 = 在 Google 结果里拿星级/FAQ 展开,点击率碾压。**

- **Product + Offer**(价格、BRL、库存、`priceValidUntil`)——每个商品页。
- **BreadcrumbList**——面包屑。
- **FAQPage**——每个集合/商品页放 3–5 条 FAQ(是不是真钻?有证书吗?可分期吗?)。全场只有 Vangolden 做了。
- **AggregateRating / Review**——收集买家评价后加,拿**星星摘要**(所有纯培育钻对手都没有)。
- Shopify 实现:多数主题自带 Product schema;FAQ/Review 用 metafields 或 app(如 JSON-LD for SEO / Judge.me 评价)。

## 6. 内容/博客日历（抢搜索流量)

> 复用你已有素材:**黄钻科普轮播**(fancy yellow)直接改写成文章;社媒风格指引的 prompt 库出配图。

**第一波(信任/异议——先发,转化最高):**
1. `Diamante cultivado é de verdade ou é falso? A resposta definitiva` → é falso(旗舰信任文)
2. `Diamante natural vs. cultivado: qual a diferença real?` → vs natural(配 4C + 价格对照表)
3. `Diamante cultivado vale a pena? Prós, contras e para quem é` → vale a pena
4. `Diamante cultivado perde valor? O que ninguém te conta` → perde valor(反转媒体叙事)

**第二波(科普 pillar——攒权威):**
5. `O que é diamante de laboratório? HPHT e CVD sem complicação`
6. `Os 4 Cs do diamante: corte, cor, pureza e quilate`
7. `Como escolher o anel de noivado perfeito (sem gastar uma fortuna)`
8. `Quanto custa um anel de noivado no Brasil? Guia 2026`
9. `Diamante cultivado preço: tabela por quilate (0,5 / 1 / 2 ct)`

**第三波(拦截 + 差异化):**
10. `Moissanita, zircônia ou diamante cultivado: qual escolher?`
11. `Formatos de diamante: oval, almofada, gota — qual combina com você`(内链形状集合页)
12. `Certificado IGI e GIA: como saber se seu diamante é autêntico`
13. `Ouro 18k x banhado a ouro: por que o barato pode sair caro`
14. `Diamantes coloridos cultivados: amarelo, rosa e azul acessíveis`(= 黄钻轮播改写)
15. `Autopresente: por que mulheres estão comprando o próprio diamante`(内链手链/耳钉)

## 7. 技术 SEO Checklist

- [ ] **绑自定义域名**(别停在 myshopify.com)——如 `1999.com.br` / `.com`;一个品牌域对信任+SEO都重要。
- [ ] **上线=可收录**:商品从 INATIVO 转 ATIVO、去掉店铺密码锁后,去 **Google Search Console** 验证域名 + 提交 sitemap(`/sitemap.xml`)。
- [ ] 语言区域 **pt-BR**;货币 BRL;hreflang(若未来加其他语言)。
- [ ] 速度/手机端:压缩商品图(你现在的图 ~1MB/张,上线前批量压到 <200KB)、懒加载。
- [ ] Shopify 变体别产生重复 URL;集合分页加 canonical。
- [ ] 404/301:改 URL 时做跳转。

## 8. 信任/转化（SEO 旁支,直接影响排名+成交）

- **laudo IGI** 写进商品页 + meta + schema(你本来就每件带证书——这是对手的弱项,放大它)。
- **评价**:上线后主动收集买家评价(接 Judge.me 等)→ 喂 AggregateRating → 拿星级摘要。
- **Pix / parcelado sem juros**:写进 meta 和集合页文案(巴西决策刚需)。
- **「ouro 18k maciço,não banhado」**:明确标"非镀金",正面回应巴西人对"便宜=假"的担忧。

## 9. 90 天路线图

**Phase 0 · 上线前地基(最重要)**
- 绑域名;搭集合页结构(类型 + 形状 + 金属 + 克拉);
- 按模板写**全部商品标题/meta/alt/handle**;上 Product+Breadcrumb+FAQ schema;
- 建 `/diamante-cultivado` 科普中心骨架;装 GSC。
- 先把 **10 个快赢商业页**做到位(标题+meta+schema齐)。

**Phase 1 · 0–30 天(信任内容)**
- 发第一波 4 篇信任/异议文(é falso / vs natural / vale a pena / perde valor);
- 商品全部 ATIVO、提交 sitemap、开始被收录。

**Phase 2 · 30–90 天(权威 + 规模)**
- 发第二、三波科普文(4Cs / 如何选 / 价格 / moissanita对比 / 形状);
- 铺**形状/金属/克拉筛选落地页**;开始程序化 SEO(`anel de noivado [formato] diamante cultivado` 批量页,这块全行业空着);
- 收评价加星级;再用已排名的长尾页**内链去带大词**(ouro 18k / aliança)。
