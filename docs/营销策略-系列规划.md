# 1999 · 营销策略 / 产品系列规划（想法记录）

> 🗒️ 状态:**草稿 / 灵感记录**(2026-08-12)。这是创始人的初步营销构想,先原样存档,**后续有时间再拉出来展开讨论**。下方「待讨论」为占位问题,非结论。

## 三大产品系列

### 1️⃣ 钻戒系列（高客单价 / 旗舰)
- **定位**:高客单价产品,品牌利润与形象锚点。
- **目标客群**:追求**仪式感**的年轻夫妻。
- **核心主张**:用**合理的价格**采购**无价的情绪价值**钻戒。
- **Slogan**:**"O 'sim' perfeito."**(完美的那声"我愿意")
- 关联:对应现有样品的 15 枚戒指(基础款 + 设计款),见 [`样品清单.md`](./样品清单.md)。

### 2️⃣ 日常首饰系列（时尚 / 复购)
- **定位**:日常佩戴、追求品质与格调的时尚线。
- **目标客群**:**时尚都市女性**,追求**品质和格调**。
- **Slogan**:**"forever mine."**
- 关联:呼应竞品调研里"走量地基"(项链/吊坠/时尚戒),见 [`竞品产品调研.md`](./竞品产品调研.md)。

### 3️⃣ 1999 系列（引流 / 入门)
- **定位**:**契合品牌名称**的**引流系列**;低门槛、走量、拉新。
- **产品**:基础的**银 + 小克拉培育钻**——如 **0.5ct 耳钉、项链**等,**一套基础入门款**。
- **目标客群**:想满足**"拥有钻石"梦想**的人。
- 关联:正对竞品调研的 **P0 补货缺口(耳钉 → Huggie → 网球手链)**;报价参考已在 [`深圳水贝成本调研.md`](./深圳水贝成本调研.md) §2.3/§2.4(0.5+0.5ct 银耳钉 ¥900/对、1ct 银项链 ¥900/条)。
