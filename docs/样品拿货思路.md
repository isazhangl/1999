# 1999 · 样品拿货思路

> 本文件记录**为什么这样拿样品、怎么取舍、以及实际进了哪些货**。
> 具体逐件清单见 [`样品清单.md`](./样品清单.md)；本文件负责"思路 + 记录"。
> 版本：v1（2026-08-09，持续更新）

---

## 一、核心原则

**用最少件数，覆盖最多用途。** 一盒样品（约 16 件）要同时干四件事：

1. **拍摄底盘** —— 用 Riverflow 把实物拍成全套电商/社媒图，撑起整个上架目录，不必一开始压大量库存。
2. **给客户看真钻** —— 手感、火彩、大小，当面打消"是不是真钻"的疑虑（配 IGI 证书）。
3. **演示定制能力** —— 让客户看到"选石 + 选托 + 选色"的选项。
4. **展示主石大小** —— 戴在手上直观对比克拉差异。

> 一句话：**样品不是库存，是"销售 + 内容 + 信任"的道具。** 先轻资产跑通，再按数据补货。

## 二、选品四大标准（拿货时的取舍逻辑）

| 标准 | 拿什么 | 为什么 |
|---|---|---|
| **① 最基础的款** | 经典圆钻四爪 solitário、单钻耳钉/吊坠、aliança 对戒 | 最百搭最好卖、谁看都不会错；圆钻 + 白金是安全牌；aliança 呼应巴西传统 |
| **② 好看吸睛的款** | Halo 显大款、Oval 椭圆、tennis 手链 | 制造"哇"的效果，适合社媒/直播/大片，拉眼球 |
| **③ 体现定制化的款** | 不同切工裸石 + 空托、不同镶嵌、不同金属色 | 核心是让客户"看到选项"，不必每件成品，重在演示"我们能定制" |
| **④ 体现主石大小** | 同款 solitário 的 0.3 / 0.5 / 1.0 / 2.0ct 阶梯 | 直观对比 + 绝佳 TikTok 内容（"同款不同克拉""1ct 真钻 vs 天然半克拉"） |

## 三、关键取舍（拿货时怎么定）

- **切工优先级**：主打**圆钻**（最百搭）+ **椭圆 Oval**（最流行）；祖母绿/枕形/梨形各带 1 颗**小裸石**用于定制演示即可，不做成品。
- **材质分层**：多数 18K（核心利润层）+ 1–2 件**银托**（入门引流层，体现价格分层）。
- **证书策略**：**0.5ct 以上每件配 IGI 证书**一起带；0.5ct 以下不带证（与说明书定价/认证策略一致）。
- **数量克制**：总计约 **15–16 件 + 一组裸石 + 证书**，一个样品盒装得下。宁可少而精，缺的款后续按销售数据补。
- **一物多用**：优先选"既能拍、又能演示、还能对比克拉"的款，避免功能重复。

## 四、和市场/定位的对应（为什么这些选择适合巴西）

- **aliança 对戒**：巴西婚俗传统是金对戒，带一对能演示"传统 + solitário 组合"，不硬推美式单钻。
- **克拉阶梯**：巴西天然钻贵（1ct ≈ R$42,300），"1ct 真钻 R$8,500"是核心钩子，阶梯样品能把这个价值感当场演示。
- **Halo 显大款**：性价比人群爱"看起来更大"，契合"够得着"定位。
- **银托入门**：呼应市场已有的低入门价（Panna 等），但用真钻 + 证书拉开差异。
- **定制演示**：本地多数品牌卖标准款，"可定制 + 透明"是差异点之一。

### 盘点结论（对照四大标准）

- **① 基础款 ✅**：圆钻六爪（序13）、祖母绿单钻（序2）、椭圆单钻（序3）都到位。
- **② 好看吸睛 ✅**：Halo 显大（序16）、三石戒（序5/7）、pavé/满钻臂多款、radiant/心形 statement。
- **③ 定制展示 ✅**：切工覆盖 **圆 / 椭圆 / 祖母绿 / 公主方 / 雷迪恩 / 心形 + 梨形侧石**；金属覆盖 **18K 白/黄/玫瑰金 + Pt950 + 14K**；镶嵌有 solitaire / 三石 / pavé / halo / hidden halo / 满钻臂 —— 定制"选项"很齐。
- **④ 主石大小 ⚠️ 半覆盖**：主石集中在 **1.0–2.1ct**，**缺 0.3/0.5ct 小克拉** —— 克拉阶梯低端要补，才能演示"从小到大"和入门价。
- **意外收获**：**3 个排戒/线戒（序1/6/10）** 天然适合做 **aliança 对戒 / 叠戴**，正好呼应巴西婚俗；**2 个吊坠**支撑日常线。

### 明显缺口（需补货）

- ❌ **英雄单品——单钻耳钉 brinco ponto de luz 没有**！（引流爆款，**优先补**）
- ❌ **tennis / riviera 手链** 没有（内容/直播抢镜款）。
- ⚠️ **小克拉（0.3/0.5ct）** 求婚戒 / 耳钉 —— 用于**克拉阶梯**与**入门价**层。
- ⚠️ **银托入门款**：本批多为 18K/Pt950（偏中高），缺 <R$2,000 的入门引流层。
