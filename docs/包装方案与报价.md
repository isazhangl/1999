## 三、待改进清单（沿用之前的"审判式"评估)

按优先级(详见当时讨论):
1. **字标(最关键)**:现「1999」压印又浅又虚、字体是通用细衬线,**无品牌字标**;盒面数字与信封花体**两套字不成系统** → 需先做**专属 logotype**,压印要更深或改烫印/UV。
2. **内构**:小盒松松丢在大盒里、四周空、会滑 → 要**贴合内托/卡槽**;戒指盒目前是**通货件**,建议定制。
3. **做工/材质**:外盒内壁裸板、边角起皱;米白/牛皮/纯白**三个白打架** → 统一色调、内里整包收紧。
4. **签名色**:目前一团中性色、无点缀、无烫箔 → 结合 VI 定**一个签名色/金属点缀**(呼应品牌色系手册)。
5. **系统件缺失**:无封缄贴/绶带/内衬;**没给证书卡+护理卡留位** → 把 [`保质证书与护理.md`](./保质证书与护理.md) 的卡片纳入盒内结构。
6. **文案**:英文贝多芬句对**巴西葡语市场**有语言隔阂 → 用葡语/双语,或参考语录库选定主句(Camões / 雅歌 / 或原创葡语)。
7. **可持续叙事**:培育钻是环保卖点,牛皮/棉纸材质应**明确标注"可持续/再生"**去占住故事。
