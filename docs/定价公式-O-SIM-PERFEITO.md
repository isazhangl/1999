# O SIM PERFEITO · 定价公式（成本法 · 创始人核定）

零售价 = **材料成本 × 6**。逐层展开(币种 ¥RMB → R$BRL,汇率 **1¥ = R$0.76**):

```
综合成本  = 产品(钻+金属) + 包装 50 + 其他材料 30
到岸成本  = 综合成本 × 3        # 运费和税 = 综合 × 200%
零售价    = 到岸成本 × 2        # 利润 = ×200%
        = 综合成本 × 6
零售R$   = 零售¥ × 0.76,  取整到最近 R$100 再 −10(尾数 X.X90)
```

> 锚点：**基础款 1ct 18K 单石 = ¥2.800**(= 2g×1100 + 1ct×600)。据此戒臂用料按 **2g** 建模;铂金暂同按 2g×1000(密度更大、实重更高可再调)。

## 二、产品成本公式（单石 SOLITAIRE）
```
产品¥(克拉, 金属) = 2g × 金属单价 + 克拉 × 600
```

## 四、其他镶嵌款（Halo / 三石 / Pavé / …）
- **由创始人逐款提供零售价**(比单石多用金 + 镶碎钻,成本更高)。
- Shopify 上这些款先以**占位价**建档,拿到定价后批量改价。

## 五、与 1999 入门线的关系
- 1999 入门线(0.5ct 银)固定 **R$1.999**;按成本法应为 R$2.590 → **1999 是低于成本法的引流锚点**,刻意保持全店最低价。
