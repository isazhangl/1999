# 1999 · 盈利模型（v1）

基于真实进货价 + 已定价格带 + 巴西进口税负,测算单件毛利、月度损益与首批回收。
**所有假设已标注,⚠️ 项需成稿前核实**(尤其进口税率、CAC、汇率)。

## 一、核心假设

| 参数 | 取值 | 来源 / 说明 |
|---|---|---|
| 汇率 | ¥1 = R$0.75 | 项目说明书 |
| **到岸系数**(FOB→到岸) | **×1.8**(区间 ×1.5–×2.3) | ⚠️ NCM 7113 税负 +50%~130%(待 Receita Federal TEC 核实) |
| 支付费率 | 2.5% | Pix≈1% 与信用卡分期≈3–4% 混合(⚠️估) |
| 物流+包装/单 | R$60 | 保价快递 + 礼盒(⚠️估) |
| 营销/CAC | 收入的 18% | DTC 早期网红+投流(⚠️估,关键变量) |
| 固定月支出 | R$2,000 | 会计 R$300 + Shopify/工具 + 杂项(不含创始人工资) |
| 证书 | 随货 IGI,已计入进货 | 说明书 |

> "到岸成本" = 进货价(FOB)× 到岸系数(含运费 + II+IPI+PIS+COFINS+ICMS)。

## 二、单件毛利（按价格层）

| 层级 | 代表款 | 进货价 FOB | 到岸(×1.8) | 零售价 | 毛利 | 毛利率 |
|---|---|---|---|---|---|---|
| **入门(银托 0.5ct)** | 引流层(库存暂无,估) | R$800 | R$1,440 | **R$2,800** | R$1,360 | **49%** |
| **主力(18K 1ct)** ⭐ | 序2 00412063(1.02ct) | R$1,946 | R$3,503 | **R$8,500** | R$4,997 | **59%** |
| **statement(2ct 三石)** | 序5 00412176(2.07ct) | R$4,056 | R$7,301 | **R$18,000** | R$10,699 | **59%** |
| **英雄耳钉(引流)** | 待补货(估) | R$650 | R$1,170 | **R$1,800** | R$630 | **35%** |

**主力 18K 1ct 的税负敏感性**(零售 R$8,500):

| 到岸系数 | 到岸成本 | 毛利 | 毛利率 |
|---|---|---|---|
| ×1.5(税负 +50%) | R$2,919 | R$5,581 | 66% |
| **×1.8(基准)** | R$3,503 | R$4,997 | **59%** |
| ×2.3(税负 +130%) | R$4,476 | R$4,024 | 47% |

> 结论:**即便最重税负,主力款毛利率仍 ~47%**——因为天然钻贵、培育钻 FOB 极低(1ct 批发已跌至 ~$168),价差撑起厚毛利。

## 五、关键杠杆与敏感性（按影响力排序)

1. **进口税务结构(最大变量)**:到岸系数从 ×2.3 优化到 ×1.5,主力款毛利率 +19 个点(47%→66%)。→ **优先做进出口/资金结构优化(说明书第 10 节)。**
2. **CAC / 营销效率**:营销从 18% 降到 10%,基准情景利润 +R$8,000/月。→ 靠创始人 IP + 自然流量(TikTok/IG)降 CAC。
3. **产品结构**:提高 18K 主力款与 statement 占比(59% 毛利),控制低毛利引流耳钉(35%)比例。
4. **客单价 / 分期**:parcelamento 提升高客单成交率,拉高 AOV。
5. **复购**:耳钉/huggie/吊坠日常线带动复购,摊薄 CAC。
