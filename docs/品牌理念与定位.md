# 1999 · 品牌理念与定位（v2 · Conscious Luxury 重定位）

> 核心转向:**不卖"更便宜的钻石",卖"更聪明、更有意识的选择"**。
> 从「preço acessível / fração do preço」→「conhecimento、escolha、consciência、access」。
> pt-BR 文案可直接用于官网/手册/社媒;中文为策略说明。创始人 2026-10 定调。

---

## 0. 一句话定位

**O novo luxo não é ter acesso ao que é raro. É ter conhecimento suficiente para escolher diferente.**
(新奢不是拥有稀有之物的门路,而是拥有足够的认知去做不同的选择。)

Slogan 保留:**A new concept of eternity**。

---

## 1. 话术原则（最重要的转向）

### ❌ 停止这样说
- "preço que cabe no seu para sempre"、"fração do preço"、"diamante mais barato"
- 任何把品牌建立在**省钱 / 便宜**之上的表达。

### ✅ 改成这样说
- **不是买更小的钻石去省钱,而是选更大的钻石,因为不必为开采的稀缺性买单。**
  > *"Você não escolhe um diamante menor para pagar menos. Escolhe um diamante maior porque não precisa pagar pela escassez da mineração."*
- 四大支柱:**luxo + inteligência + consciência + design**。
- **技术事实 → 欲望论据**:"同成分、同结构、同光泽,只差来源" 不再只是科普,而是**"聪明人的选择"**的理由。
  > *"Mesma composição, mesma estrutura, mesmo brilho. Muda só a origem — e a inteligência de quem escolhe."*

### 价格怎么处理
- 价格**不做主轴**、不进品牌叙事首页。报价留在成交环节(私洽/产品页),而不是品牌故事里。

## 2. Manifesto（品牌宣言 · pt-BR）

> Na 1999, o novo luxo não é ter acesso ao que é raro — é ter **conhecimento** para escolher diferente.
>
> Nossos diamantes têm a mesma composição, a mesma estrutura e o mesmo brilho dos diamantes extraídos da terra. Muda apenas a origem. Você não escolhe um diamante menor para pagar menos — escolhe um diamante **maior**, melhor, porque não precisa pagar pela escassez da mineração.
>
> Isso é luxo com **inteligência, consciência e design**. Um diamante de verdade, pela razão certa.
>
> *A new concept of eternity.*

## 3. Para quem é a 1999?（定位人群 · pt-BR）

> **Para quem não compra para provar que pode. Compra porque sabe o que quer.**
> Para quem entende que luxo também é **liberdade de escolha**.

- Para quem quer um **diamante maior**, sem abrir mão da verdade.
- Para quem **valoriza design**.
- Para quem quer **personalização** — uma joia só sua.
- Para quem **não precisa seguir o padrão tradicional**.
- Para quem quer **presentear de forma extraordinária**.
- Para quem quer construir uma joia **com significado**.

> 🈶 用途:官网 "Sobre"、品牌手册新增一页、提案 PPT 的人群页。

## 4. 体验与会员体系（desejo por acesso, não por desconto）

> 核心逻辑:对目标人群,**给的是 access(通路/体验/关系),不是 discount(折扣)**。以下为分阶段蓝图。

### 4.1 **1999 Private** — 私人定制体验
一对一、预约制,上门/办公室/酒店/私密空间。
顾客亲自走一遍:**formato → quilate → cor → pureza → metal → cravação**。
话术不是 *"Escolha sua joia"*,而是 ***"Vamos desenhar seu diamante."***
> 🈶 把"卖货"升级成"共同设计",第一步就能落地(现在就能用这套话术做私洽)。

### 4.2 **1999 Diamond Session** — 情侣共创体验
不是卖戒指,是卖**"一起创造戒指"的经历**。情侣共同参与:
展示裸钻 → 对比克拉 → 选形状 → 选金属 → 设计 → 试戴 → 证书 → 交付。
**旅程本身成为记忆的一部分。**
> 🈶 高情感、高传播(天然适合拍 Reels/纪录片式内容),强差异化。

### 4.3 **First Diamond** — "第一颗真正属于你的钻石"
针对年轻、家境优渥的人群的洞察:**哪一件才是第一件真正属于"你自己"的珠宝?**(不是妈妈/外婆的传承)。1999 占住这块心智。
> *"Seu primeiro diamante. Sua primeira história."*
> 🈶 可做成一个入门系列概念(类似 Pandora 的系列逻辑),且这个人今后会复购品牌其他作品 → 终身价值。

### 4.4 **Edições por Convite** — 邀请制限量联名
例:**1999 × [designer/arquiteto]**,20 件、编号、仅限邀请。
= 人为稀缺 + 设计 + 关系 + 欲望 → 让品牌进入**收藏品(colecionáveis)** 领域。
> 🈶 中远期布局,建立品牌高度与收藏属性。

### 4.5 **1999 Circle** — 私密会员圈层
**不是"推荐好友得折扣"**,而是一个私密客户圈,给的是**access**:
- 系列抢先体验(acesso antecipado)
- 专属单品(peças exclusivas)
- 私人接待(atendimento privado)
- 活动 / gastronomia / 发布会 / 与设计师见面
- 共创定制机会(desenvolver peças sob medida)
> **A pessoa não recebe desconto. Ela recebe acesso.**
> 🈶 这比"折扣推荐"对高端人群**更贴切、更长效**,也保护价格体系。
