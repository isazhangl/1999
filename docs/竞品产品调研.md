|---|---|
| 覆盖品牌 | **Ring Concierge**、**Brilliant Earth**、**Vrai**、**Mejuri**、Kendra Scott、Aurate、Ana Luisa |

> ⚠️ **数据限制(重要)**:本项目云端环境的出口代理**拦截了各品牌官网**(ringconcierge.com / brilliantearth.com / vrai.com / mejuri.com 均 `EGRESS_BLOCKED`),且各站评论数由 Okendo/Yotpo 插件动态渲染,**不进搜索摘要**。因此**多数单品的精确评论数"未取得"**,价格多为搜索摘要(标注)。结论基于畅销结构与可核实信号,**评论数请当定性信号看**。要精确的"每款 X reviews"排序,可用 **Apify 爬虫**直连抓取(见第五节)。

## 一、核心结论(一页看懂)

1. **走量地基 = 耳饰 + 日常吊坠,而非订婚戒。** 跨品牌看,评论数最密集、最好卖的是:
   - **耳环**:① huggie hoops(密镶/纯金小圈)② diamond studs(单钻/培育钻钉)
   - **项链**:小巧的**单石 / 密镶日常吊坠**(可叠戴)
2. **英雄单品打法(Ring Concierge 模板):** 用一款 **Mini Tennis 项链/手链(各 $898)** 做现金牛(Mini Tennis 手链累计卖了 **$1200 万**),再做 **Mini → Classic → Luxe 价格阶梯** + **同款天然/培育双价位**。RC 成品珠宝已占营收 **60%**,超过订婚戒。
3. **订婚戒 = 获客与形象,非起量主力。** 基础盘是**圆钻单石(solitaire 爪镶)**,**椭圆(oval)**是当下最热时尚切工,**祖母绿**为进阶;流行 setting:hidden halo、pavé 密钉臂、whisper-thin 细臂。
4. **一个铁律:越平价、越日常、越易叠戴,评论数越高**(百元级 huggie / pendant 的评论数远超高客单网球款)。
5. **培育钻的机会点 = 把"网球(tennis)"这种高需求形态做价格降维**(切入 $300–600 的真钻网球手链/项链,填 Mejuri 彩宝款与 Vrai/Aurate 培育钻款之间的空档)。

### 对 1999 的针对性启示（基于 BE 实测榜）
