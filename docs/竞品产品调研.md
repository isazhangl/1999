## 一、核心结论(一页看懂)

1. **网球手链 = 全行业头号现金牛。** Ring Concierge 评论数第 1(**Mini Tennis Bracelet 1,045 条**),Brilliant Earth 畅销榜第 1(**Petite Tennis Bracelet $695**)。两家榜首同为网球手链。
2. **耳饰(huggie 小圈 + 钻石耳钉)是"上榜款数最多"的走量地基。** 四家都重仓,入门价极低(RC studs $138 起、huggie $159 起),靠低门槛堆评论与复购。
3. **$200–400 的亲民日常项链/吊坠才是评论主力**(RC 一款 $398 项链 779 条、$248 字母吊坠 283 条),**远超高客单网球项链**($3,448 的只有 235 条)。
4. **英雄款必做"价格阶梯" + "天然/培育双价位"。** RC 网球手链做 $159/$1,098/$2,498;BE 耳钉 $340→$1,195;Bel 同款天然 vs 培育并列(Gabriella €3,220→培育 €1,600,**省 50%**)。
5. **一套"通用标配珠宝"是所有品牌(连婚戒主导的 Bel)都必备的**:网球手链 / huggie / 钻石耳钉 / 单石吊坠 / bezel station 手链+吊坠。**1999 目前基本没有这套。**
6. **两种品牌模型都成立**:珠宝主导(RC/BE)靠走量珠宝;婚戒主导(Bel)靠命名订婚戒系列 + 培育版拉低门槛。大众综合型(Happy)额外重仓字母项链 / 十字架 / 男戒。

## 四、对 1999 的补货优先级清单

**现状(见 `docs/样品拿货思路.md`)**:已进 17 件,其中 **12 件是女款订婚/戒指**,吊坠仅 2 件,**网球手链 / huggie / 钻石耳钉 = 0**。→ **走量地基几乎空白,补货方向非常明确。**

| 优先级 | 补什么 | 为什么 | 建议做法 |
|---|---|---|---|
| **P0** | **钻石耳钉(四爪)** | 全行业上榜款最多、入门价最低、复购强 | 做**克拉阶梯**(0.5→1→1.5→2ct),入门价压到最低档 |
| **P0** | **Huggie 小圈耳环** | 四家都重仓,日常"戴上不摘" | 素金 + pavé 两版,亲民入门款 |
| **P0** | **网球手链** | 全行业头号现金牛 | **必做一个亲民入门款**(对标 RC $159 / BE $695)+ 经典款,做价格阶梯 |
| **P1** | **单石吊坠 + 字母/个性化项链** | $200–400 价位评论主力;巴西个性化/宗教需求 | 单石阶梯 + 字母/十字架定制 |
| **P1** | **Bezel Station 手链 + 吊坠** | RC/Bel 均走量,现代极简 | 成对做 |
| **P2** | 订婚戒(已有 12 件) | 获客/形象/情感内容,非走量主力 | 拍大片讲品牌;培育版打"同款省 20–50%" |

**定价锚点**:RC(USD)—— 耳钉 $138–498 起、huggie $159–659、网球手链 $159–2,498;Bel(EUR)—— 标配珠宝 €780–2,970、订婚戒 €780–4,380。**1999 落地时换算为 BRL 并结合培育钻成本定价,主打"同款设计更大更省"。**

**两条通用增长手法(务必照抄)**:
1. **英雄款做价格/克拉阶梯**(同款多价位,替客户按预算决策)。
2. **产品页突出评论数 + 星级**(RC 的评论数就是它的转化货币;新品牌从第一天就积累与展示)。
