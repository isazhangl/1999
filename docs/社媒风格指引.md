## 一、风格 DNA（判断标准 / 出图验收清单）

一张图是否"对味"，对照这 6 条，命中 ≥4 条才算合格：

1. **暖中性色盘**：焦糖 / 米 / 奶油 / 暖木 / 灰褐 + 金；低饱和、暖白平衡。**无冷调、无高饱和。**
2. **自然窗光**：柔和、有方向、带金色暖意、柔影。**禁硬闪光、禁死白。**
3. **留白**：主体周围有呼吸空间；构图安静、极简。
4. **可触表面**：木托盘 / 绒布 / 亚麻 / 皮肤；哑光质感。
5. **人味**：手在挑选/整理/试戴，或工坊工具/做工细节（建立"真钻·可信"信任感）。
6. **考究的小巧思**：托盘网格、意外物件搭配（勺子/书/石头）、单件 hero 大留白。

**参考色值**（调色/背景/道具选色用）：
`奶油白 #F3ECE1` · `暖白 #FAF7F2` · `焦糖 #C8A97E` · `灰褐 #A38B6D` · `暖棕 #6E5844` · `缎面金 #B8A88A` · `炭灰 #2B2B2B`

## 二、内容支柱（5 大类，轮着发）

| 支柱 | 拍什么 | 作用 |
|---|---|---|
| **1. Produto（产品 hero）** | 单件微距，暖光 + 大留白 | 展示美、种草 |
| **2. No corpo（上身）** | 手/耳/颈局部，真实皮肤，试戴 | 尺寸感、代入感 |
| **3. Atelier / Bastidores（工坊/幕后）** | 工具、做工、证书、托盘整理 | **信任**（培育钻=真钻、laudo、personalização） |
| **4. Curadoria（策展/平铺）** | 木托盘网格、系列合集、"escolha o seu" | 展示系列、SKU 广度 |
| **5. História（品牌/情绪）** | para sempre、安静叙事、短句 | 品牌温度 |

**建议节奏**：每周 4–5 帖，5 个支柱轮转；Reels 每周 2–3 条（挑戒指的手、开箱、钻石闪光微距、上身）。

## 三、文案（Caption）语气 · pt-BR

- **短、暖、亲密**，偶尔诗意但不做作；第一句就是钩子。
- 每帖带**一个信任点**（diamante cultivado = de verdade / com laudo / personalização / garantia）。
- 品牌语收尾：*para sempre*。
- 结构：`钩子 → 一句故事/细节 → 一个信任点 → CTA（DM/link）→ hashtags`

**示例**：
> Um brilho que combina com o seu "sim". ✨
> Diamante cultivado em laboratório — de verdade, sempre com laudo.
> Personalize o formato, o quilate e o metal.
> 📩 Chame no direct para criar o seu.
> #1999 #diamantecultivado #aneldenoivado #parasempre

**Hashtag 组**（混用）：品牌 `#1999 #parasempre`；品类 `#aneldenoivado #brincodediamante #aliança`；教育 `#diamantecultivado #labgrown`；本地 `#joiassãopaulo #noivadobrasil`。

## 四、AI Prompt 库（可复用）

### 通用模板（英文出图最稳）
```
[shot type] of [product], [material], resting on [warm neutral surface: walnut wood tray / beige velvet / natural linen],
soft natural window light, warm golden tone, generous negative space, minimal quiet-luxury editorial jewelry photography,
muted warm palette (camel, cream, soft brown, gold), matte tactile textures, shallow depth of field,
photorealistic, high detail. aspect 4:5
```
- **产品要 1:1 还原** → 用 Nano Banana + 你的实拍图当 reference（Riverflow）。
- **只要氛围/场景**（无需精确产品）→ 文生图即可（Nano Banana / Midjourney）。
- 负向（Midjourney 加 `--no`）：`harsh flash, cool tones, oversaturated, cluttered, plastic, busy background`。
