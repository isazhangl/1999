# 1999 · Campaign 设计指南（方法论 + 巴西落地 + 首案）

怎么设计一个营销 campaign,拆成三块:**① 通用框架(照着填)** → **② 巴西落地(日历/网红/支付/文化)** → **③ 1999 首个 campaign 具体方案**。
配套文档:品牌定位见 [`项目说明书.md`](./项目说明书.md)、单位经济见 [`盈利模型.md`](./盈利模型.md)、竞品见 [`竞品产品调研.md`](./竞品产品调研.md)、出图见 [`prompt学习库.md`](./prompt学习库.md) / [`MJ速用卡.md`](./MJ速用卡.md)。

> 一句话总纲:**一战只锁一个大创意、一个英雄单品、一个主 KPI**。分散是小预算最大的浪费。

## 一、Campaign 标准框架(照着填的 checklist)

一个完整 campaign 的骨架 = **四个不可省要素(目标 / 受众 / 核心信息 / 时长)** + 渠道 / 内容 / 阶段 / KPI / 预算。

| 模块 | 关键问题 | 要点 | 1999 具体化 |
|---|---|---|---|
| **1. 目标 Objective** | 这次要达成什么?**一个 campaign 只锁一个主目标** | 认知 / 转化 / 发布 三选一,用 SMART 写死(可衡量+有时限) | 新品牌首战 = **发布 + 认知**(不是硬转化) |
| **2. 受众 + 洞察** | 卖给谁?他们真正在意什么? | 做 persona + 找一条"扎心洞察" | 25–38 岁巴西女性,**自购(autopresente)**为主;洞察:"她不想等别人送,想为自己的里程碑买件对得起自己的真钻" |
| **3. 大创意 Big Idea** | 一句话能记住的核心概念 | 一个 campaign 一个概念;**情感 > 功能** | **"1999 = para sempre(永远)"** + 培育钻"真钻·透明·够得着" |
| **4. 核心信息 + 钩子** | 一句主张 + 一个行动理由 | message 只留一条;offer(候补 / 限量 / 刻字 / 分期)驱动转化 | 主张:*同样是真钻,透明定价,只为你自己的时刻*;钩子:候补专享 + 首发限量 + **12x sem juros** |
| **5. 渠道组合** | 在哪里触达? | 不要平摊,每支柱选一个强打法 | **TikTok 引流 + Instagram 建信任 + 葡语独立站成交**(已定) |
| **6. 内容计划** | 用什么素材讲? | 英雄视频 + 系列内容 + UGC + 教育 | 英雄单品特写 + 创始人出镜 + 开箱 + before/after + 培育钻科普 |
| **7. 阶段 Phasing** | 什么时候推什么? | 预热→发布→持续→社会证明→收尾 | 提前 **30–90 天蓄水建候补名单** |
| **8. KPI / 衡量** | 怎么算成功? | 目标不同 KPI 不同(见下) | 发布看候补人数 / 首周售罄率 / CVR |
| **9. 预算分配** | 钱怎么花? | **预热 30% / 发布周 40% / 后续 20% / 迭代 10%** | 大头压发布周,把 Meta 算法喂出学习期 |

### 阶段时间线(Phasing)

| 阶段 | 目的 | 时长 | 主要动作 | 阶段 KPI |
|---|---|---|---|---|
| **Teaser 预热** | 蓄水 / 建期待 | 发布前 30–90 天 | 候补落地页 + 邮件/SMS 名单(目标 ≥500)、低预算认知广告($10–30/天)暖人群、网红提前 seeding | 名单人数、CPL |
| **Launch 发布** | 集中转化 | 发布周(3–7 天) | 英雄单品 + 发布限量/福利、创始人发布视频、集中投放喂算法学习期 | 首周 GMV、CVR、售罄率 |
| **Sustain 持续** | 维持热度 | 发布后 2–6 周 | 系列内容滚动、复投赢家素材、扩人群 | ROAS、CAC |
| **UGC/社会证明** | 破"新品牌无评价"信任缺口 | 全程 + 发布后加码 | 收集买家 UGC / 评价 / 开箱、网红二发 | UGC 数、评价数 |
| **Close 收尾** | 结算 + 沉淀 | 结束 1–2 周 | 复盘、把 UGC 沉淀成常青素材、10% 预算迭代赢家 | 留存、LTV、复购 |

## 三、社媒格式(TikTok / Reels / IG)

**黄金法则:前 2–3 秒定生死。** 观众滑动只给你 2–3 秒,开头必须**视觉冲击**(快速运动/大字幕)或**反差金句**("我差点没买它,结果……")。

| 格式 | 为什么有效 | 珠宝怎么拍 |
|---|---|---|
| **Before/After** | 转化弧天然贴短视频 | 素颈→叠戴;裸手→佩戴;旧戒→新戒 |
| **开箱 Unboxing** | 还原收货体验,回答"到手长啥样" | 礼盒 + 证书 + 上手第一反应(送礼仪式感=核心情绪) |
| **教程/叠戴** | 建专业感 | 如何叠戴、如何选克拉/切工、培育钻科普 |
| **评价/见证** | 社会证明破信任 | 真实买家佩戴 + 口述理由 |
| **生活方式** | 场景代入 | 约会/通勤/送礼时刻,绑"日常轻奢" |
| **创始人故事** | 最便宜的差异化 | 讲初衷/工艺/定价透明 |

时长:TikTok/Shorts **15–30 秒**;Reels/广告叙事精彩可到 **45–60 秒**。
**系列内容**:把大创意拆成可持续栏目("每周一款叠戴""透明定价拆解""培育钻 vs 天然钻 真相")养账号、喂算法。

## 四、巴西营销日历(珠宝视角)

送礼型节点集中在上半年,**Dia dos Namorados 是珠宝全年最大档**;年底 Q4(Black November + 圣诞)贡献很多商家 30%+ 年营收。

| 节点 | 2026/27 日期 | 珠宝意义 | 预热窗口 |
|---|---|---|---|
| **Dia da Mulher 妇女节** | 3/8 | 女性**自购(autopresente)**、犒赏;非求婚档,主打"庆祝女性成就" | 提前 2 周 |
| **Dia das Mães 母亲节** | 5 月第二个周日 | 上半年零售大档,送妈妈 | 提前 3–4 周 |
| **Dia dos Namorados 巴西情人节** | **6/12(固定)** | **珠宝全年最大档**;求婚戒(anel de noivado)、对戒(aliança)、情侣互赠核心 | 提前 3–4 周(5 月中启动) |
| **Dia dos Pais 父亲节** | 8 月第二个周日 | 男性向偏弱,做男款手链/戒指补充 | 提前 2–3 周 |
| **Black Friday / Black November** | 11 月最后一个周五 | 高客单转化窗口;成熟品牌做**整月** | **整个 11 月**(非单日) |
| **Natal 圣诞** | 12/25 | 情感送礼高峰,礼盒/个性化;**12 月初就上架** | 11 月底衔接 BF |

> 主轴:上半年(妇女节→母亲节→情人节)"送礼+求婚";下半年靠 Black November + 圣诞"折扣+分期"拉客单。求婚戒/对戒内容重心压在 **Dia dos Namorados**。

## 五、巴西落地打法(网红 / 支付 / 文化)

**社媒生态**:活跃用户 1.6 亿+,日均 3h42m;IG 约 1.47 亿(全球最大创作者国之一);TikTok 月活约 9,170 万、互动率约 3.7%(约 IG 的 8 倍),**62% 用户关注网红、71% 通过 TikTok 发现新品**。
**网红打法**:**纳米/微网红互动率 4–8%**,远高于头部,最适合转化导向的珠宝带货 —— 让买家晒单/拆盒/佩戴,再授权二次剪成广告素材。

**支付钩子(高客单成交杠杆)** —— 巴西"看月供不看总价":
- **卡免息分期(parcelado sem juros)**:珠宝行业默认动作,普遍 **10x–12x sem juros**。**文案把月供前置**:"12x de R$XX sem juros" 比总价更能推。
- **Pix**:即时转账,覆盖无卡人群,适合做"Pix 专属折扣"钩子。
- **Pix Parcelado**:典型 **4x sem juros**(每两周一期);商家仍一次性收全额净值(约 D+3),不担利息 —— 现金流友好。约 **25% 弃购源于缺分期选项**。
- 组合:落地页主打 **"12x sem juros"** 月供叙事;结账并列 **Pix + 卡免息分期 + Pix Parcelado** 三选一降摩擦。

**文化 / 语言注意**:
- 用 **巴西葡语(pt-BR)**,不要美式直译。情人节 = **Dia dos Namorados**(非 Valentine's Day),送礼 = **presente**。调性**情感、温暖、亲近**,重"人与关系与时刻",轻参数。
- **婚俗 aliança 三阶段**:namoro(恋爱对戒)→ noivado(订婚)→ casamento(结婚),是关系升级的连续叙事,珠宝绑定每一阶段。
- **戴法(与欧美不同!)**:**订婚戴右手无名指,婚后移到左手**。视觉/文案别照搬美式"左手订婚"。
- **女性自购轴**:约 85% 珠宝买家为女性、约 60% 出于"自我认可";妇女节尤其适合"送自己"叙事,也可全年作独立产品线沟通。
- **培育钻在巴西仍属早期、认知低** → **教育型内容是必要动作**(什么是 lab-grown、与天然钻区别、性价比、IGI 证书、可持续)。参考本地 Niliz(回收金+IGI)、Aurora。

## 六、1999 首个 Campaign · 具体方案

> 首案还没定"主打哪个方向"。下面给一个**推荐方案(把三个方向收进同一战役)** + 一张**方向选择表**。你选定后我把排期和文案往那儿收细。

### 推荐:品牌发布战 ×「英雄款单钻耳钉」×「para sempre」叙事,发布周落在 Q4 前

**为什么这么收**:① 品牌要先有"发布"才有后续 ② 英雄款单钻耳钉(brinco ponto de luz)已定,是低门槛、好拍、好送礼、易复购的引流入口 ③ 发布周若定在 **10 月中—下旬**,正好把余温接进 **Black November(整月)+ Natal**,首战认知直接叠上巴西年底最大转化窗口。—— 三个方向(发布 / 节点 / 英雄款)一次吃到。

| 模块 | 首案填法 |
|---|---|
| **目标** | 发布 + 认知。SMART 示例:发布后首月候补名单 3,000、首周英雄款(耳钉)售罄率 ≥60%、自然涨粉 5,000(按自身体量调) |
| **受众 + 洞察** | 25–38 岁巴西女性,自购为主;"她想为自己的里程碑买件对得起自己的真钻" |
| **大创意** | **"Para sempre começa aqui / 永远从这里开始"** —— 把 1999 的永恒之爱 + 培育钻真钻透明绑一起 |
| **英雄单品** | 单钻耳钉 **brinco ponto de luz**(引流);求婚戒/对戒作情感峰值内容与高客单变现,不铺全线 |
| **核心信息** | *同样是真钻,透明定价,只为你自己的时刻。* |
| **钩子/Offer** | 候补名单专享 + 首发限量 + 首周下单**送刻字**;落地页主打 **12x sem juros** |
| **渠道** | TikTok(引流/科普/开箱)+ Instagram(创始人 IP/信任)+ 葡语独立站(成交,三种分期并列) |

### 8 周排期(可直接用)

| 周次 | 阶段 | 动作 |
|---|---|---|
| **W-8 ~ W-4** | 预热蓄水 | 上线候补落地页;创始人出镜"我为什么做 1999"系列;微网红送样 seeding(20–50 位);$10–30/天暖人群;建邮件/SMS 名单 |
| **W-3 ~ W-1** | 造势 | 英雄款 teaser(工艺/溯源/before-after);候补名单邮件倒计时;公布发布日 + 专享福利;培育钻科普("真钻·1/4 价·IGI") |
| **W0 发布周** | Launch | 创始人发布视频 + 耳钉限量开卖;**40% 预算**集中投放;网红同步二发带联盟码;开箱内容首波上线 |
| **W1 ~ W4** | 持续 + 社会证明 | 复投赢家素材;滚动 UGC/评价;叠戴教学系列;扩人群;衔接 **Black November** 分期钩子 |
| **W5** | 收尾 | 复盘 KPI;UGC 沉淀成常青素材;留存邮件;10% 预算迭代赢家 |

### 最小可行素材清单(用现有出图能力就能做)
- 1 条英雄视频(发布主片)+ 3 张耳钉产品图(白底 3 角度,见 [`样品清单.md`](./样品清单.md))+ 1 张场景图(海滩金光模特 mood 已有成功配方,见 [`prompt学习库.md`](./prompt学习库.md) #003)
- 创始人故事 3 条(初衷 / 工艺 / 透明定价)—— 手机直拍即可,真实 > 精修
- Before/After 2 条、开箱 2 条、叠戴教学 2 条
- 网红二创若干(送样换内容)
- 候补落地页 + 3 封预热邮件(倒计时)+ 发布日 SMS
- 葡语文案对齐第五节:pt-BR、情感叙事、月供前置、右手订婚

### KPI / 预算
| 阶段 | 主 KPI | | 预算 |
|---|---|---|---|
| 预热 | 候补名单、CPL | | 预热 **30%** |
| 发布 | 首周 GMV、CVR、售罄率、ROAS | | 发布周 **40%** |
| 持续 | CAC、复访、UGC 数 | | 后续 **20%** |
| 收尾 | 留存、LTV、复购 | | 迭代预留 **10%** |
> 网红尽量走"送样 + 成交分佣",把固定成本变可变成本。

### 三方向选择表(你定方向,我收细)

| 方向 | 什么时候适合 | 大创意锚点 | 首选节点 |
|---|---|---|---|
| **① 品牌发布**(推荐) | 现在就要打响"1999 = 够得着的真钻" | "Para sempre começa aqui" + 英雄款耳钉 | 发布周落 10 月,接 Black November + Natal |
| **② 冲一个节点** | 想吃现成流量高峰 | 节点情绪(自购/送妈妈/求婚) | 妇女节 3/8(自购)或 **Dia dos Namorados 6/12**(求婚戒,全年最大档) |
| **③ 推一个英雄款** | 想先把一个爆款打透再谈品牌 | 单品透明定价 + before/after + 叠戴 | 任意,常青投放 |

> 三者不冲突:推荐方案本质是"以①为骨架、把③英雄款当主角、把余温接到②年底节点"。你给个侧重,我把文案、素材、投放排期往那个方向收。
