# ANVISA 合规排期(细化)

如何安排 PBA/LTA、LS、AFE 三大模块,每项工作**具体是干嘛的**、要多久、谁来做、能否提前。

## 一张图看懂依赖

```
PBA/LTA(批准建筑布局) → LS(卫生许可+现场检查) → AFE(联邦运营授权)
        ↑ 前置准备(.dwg图 / 物业改造 / RT登记 / ANVISA预注册)可现在并行
```

- **为什么串行**:AFE 需要 LS 出具的"满意检查报告";LS 检查前建筑要按 PBA 批准的方案改好。
- **怎么压缩**:官方审核的等待期里,把 DSL 备料、物业改造、RT 登记全部并行做掉。

---

## 阶段 0 · 前置准备(现在就能做,不依赖任何审批)

这一阶段是**加速的关键**——挂靠的是企业(CNPJ)和地址,你都已具备,不需要等 PBA。

| 工作 | 这项是用来干嘛的 | 耗时 | 谁做 |
|------|----------------|------|------|
| **交付 `.dwg` 平面图** | PBA 制图的原始输入,DSL 拿它才能画合规图纸。**缺它整条线停摆**,是起跑发令枪。 | 即时(找到文件) | 你 |
| **物业物理改造**<br>(WC PNE 无障碍卫生间、DML 清洁间、废弃物暂存间、通风) | 满足卫生检查的**硬件门槛**,LS 现场检查时场所必须达标。边等 PBA 边施工。 | 数周 | 你 + 施工 |
| **RT 技术负责人登记** | LS 申请与检查都**强制要求**已登记的 RT;化妆品通常需药师 + CRF 注册。详见[RT 专题](#rt-技术负责人可提前) | 1–4 周 | DSL + 你聘人 |
| **ANVISA 账号预注册**<br>(企业与负责人) | AFE 阶段要用,提前把账号/主体建好,到时直接递交省时间。 | 数天 | DSL |

---

## 阶段 1 · PBA/LTA — 建筑项目 / 技术评估报告

> **整体用途**:让 VISA 批准"场所的建筑布局符合卫生规范"。这是 LS 的前提——房子合不合规,先在图纸上过一遍。

| 工作 | 这项是用来干嘛的 |
|------|----------------|
| **建筑图**(家具布局、剖面、立面、动线) | 证明分区合理、物流动线不交叉污染(收货→储存→发货不回流)、符合卫生监管对布局的要求。 |
| **实施图**(Projeto de implantação) | 表明场所在园区内的定位与总平面布置。 |
| **说明书**(Memorial descritivo) | 文字说明建筑用途、用材、采取的卫生措施,配合图纸。 |
| **ART**(技术责任注册) | 由有资质的工程师/建筑师签字,对图纸**承担法律技术责任**。 |
| **递交 VISA 审核** | 官方审批建筑方案,批准后才能进入 LS。 |

**耗时**:DSL 制图 ~2 周 → VISA 审核 **30–90 天**。
**你要提供**:可编辑 `.dwg` 平面图(见阶段 0)。

---

## 阶段 2 · LS — 卫生许可(Licença Sanitária)

> **整体用途**:拿到卫生许可,并让 VISA 出具**满意的检查报告**——这份报告是 AFE 的硬前提。

| 工作 | 这项是用来干嘛的 |
|------|----------------|
| **RT 技术负责人登记** | 指定并登记对卫生质量负责的技术专业人员;申请与检查都要核对。**建议在阶段 0 就前置完成**。 |
| **良好操作手册**(Manual de Boas Práticas) | 规定仓储/分销**全流程**的卫生与质量操作标准,是体系的总纲。 |
| **POP 标准操作程序** | 把每个具体操作(收货、储存、发货、清洁、虫害控制…)写成**可执行步骤**;现场检查会逐条核对。 |
| **SGQ 质量体系培训** | 培训员工按手册/POP 执行,建立可运转的质量管理体系。 |
| **递交 LS 申请 + 陪同现场检查** | VISA 实地核查**硬件 + 文件 + 人员**;通过后发卫生许可。 |
| **复核 VISA 检查报告** | 确认报告结论"满意",这是能否进入 AFE 的关键。 |

**耗时**:DSL 备料 ~4 周(可在 PBA 审核期并行,不占主线)→ VISA 审核 **30–90 天**。

---

## 阶段 3 · AFE — 运营授权(分销与进口)

> **整体用途**:取得**联邦级(ANVISA)运营授权**,这是化妆品分销/进口能合法运营的最终资质。

| 工作 | 这项是用来干嘛的 |
|------|----------------|
| **企业与负责人注册**(已在阶段 0 预注册) | 在 ANVISA 系统建立公司主体与责任人档案。 |
| **规模认定**(Enquadramento de Porte) | 按企业规模确定 ANVISA 的收费档次与分类。 |
| **递交 AFE 申请 + 跟进至公布** | 提交联邦授权申请,处理补正,跟进到批准。 |
| **AFE 公布于联邦公报**(DOU) | 授权正式生效——此后方可运营监管类产品。 |

**前提**:阶段 2 的满意检查报告。
**耗时**:DSL 备料 ~1 周(可提前)→ ANVISA 审核 **30–60 天**。

---

## RT 技术负责人:可提前 {#rt-技术负责人可提前}

- **何时核查**:LS 递交与现场检查、AFE 都要求已登记的 RT → 必须在 **LS 递交前**就位。
- **要多久**:登记本身 1–4 周;真正的 lead time 在"找到合适的人"。
- **能否提前**:✅ 能,且强烈建议。挂靠 CNPJ + 地址(均已具备),不依赖 PBA。
- **待 DSL 确认**:①RT 由 DSL 提供还是你自聘?②化妆品+分销+进口对应哪种专业/委员会(药师/CRF-SP?)③能否现在就并行登记,还是需先通过 LS 检查?

## 现在就该做(按优先级)

1. **把 `.dwg` 平面图交给 DSL** —— 解锁 PBA,不给则整条线不动。
2. **确认并启动物业改造清单**(WC PNE / DML / 废弃物间 / 通风)。
3. **并行启动 RT 登记 + ANVISA 预注册 + LS 备料**,别串行等待。
4. **过渡营收**:非化妆品类普通商品仓储若经 DSL 确认合规,可在办理期间先运营(见[合规-ANVISA](合规-ANVISA.md))。

> 数据来源:DSL Consult 提案 Nº 1181。周期均为估算,实际以 VISA/ANVISA 受理进度为准;RT 专业类别与提前登记可行性以 DSL 正式答复为准。
