1. 提交全部文件后,预计 **45 天**内分析/裁决。
2. 批准后,外交部(MRE)下发指令,外国人凭此到指定地点**盖章护照** —— 盖章地点一经确定**不可更改**。

4. 服务在签证获批时终止。
