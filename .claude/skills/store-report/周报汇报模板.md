# 周报汇报模板（中文，发在聊天里；Excel 周报和看板截图另外作为文件发）

照下面的结构写，数字全部取自脚本输出 / 报表，不要估算。每家店一节；两家店都有时最后加「两店对比」。
语气简短直接：先给结论，再给表，最后 2–3 条要点。没有目标的指标不写目标列。

---

## {门店} 周报（{开始 dd/mm} – {结束 dd/mm}）

**目标达成**（截至 {结束 dd/mm}，按每日目标应完成全月的 {目标进度}%，剩余营业日 {N} 天）

| 指标 | 实际 / 月目标 | 月达成 | 同期达成 | 剩余每个营业日需完成 |
|---|---|---|---|---|
| 权益金 | {实际} / {月目标} | {x}% | ✓/✗ {y}% | R$ {剩余日均} |
| 营业额 | … | … | … | R$ … |
| 总客次 | … | … | … | 约 {n} 人次 |
| 新客成交率 | {实际}% / {目标}% | {x}% | ✓/✗ | — |
| 体验客单价（有目标才写） | … | … | … | — |

- **跟上的**：哪些指标 ✓ 或接近同期目标，靠什么（例如会员消耗、某个项目分类）。
- **最大缺口**：差距最大的指标，后面每个营业日要做到多少。
- **原因**：用数据说明（新客数量、成交人数、成交率、客单价、各周走势里哪一周掉了）。

**本月数据**（只列关键的，完整 12 项在 Excel 里）
- 权益金 / 营业额 / 总客次（新客 · 会员 · 网红）/ 成交人数（新客成交 · 会员续卡）· 成交客单 / 新客成交率 / 会员复购率 · 续卡金额 / 体验客单价 / 叠加率 / 二次券
- 权益金拆解：卖套餐 / 二次券 / 体验 / 线上卖券 各多少、占比，哪一块比上周变化最大。
- 人效（客次/人/天）：月度、本周，和上周比；每日最高 / 最低的一天（「人效」页）。
- 各周：哪一周明显好或差；进行中的周要注明「截至 dd/mm」。
- 员工：业绩前 2–3 名；周度走势明显变化的人；「未指定员工」金额（店内销售没填员工）。
- 项目分类：客次 / 营业额占比最高的分类和项目；新客 vs 会员偏好的差异。

**数据检查**：脚本输出里的 ⚠ 提示原样说明（新支付方式、产品销售、组合支付拆分行、跨月、目标月份不符等）。
没有当月目标时写：「{门店} 还没有 {YYYY-MM} 的目标，发给我就补上目标达成。」
